BEFORE YOU JOIN

你可能想知道。

現在加入，需要付費嗎？

LINE 社群就是這次的等待名單，免費加入。你可以在裡面追蹤實作紀錄、製作進度與後續開放通知。

加入後，更新會另外收費嗎？

不會。只要你在社群裡，就能持續取得社群內發布的內容與後續更新。新增實作、方法整理或版本更新，都不會再另外收費。

需要電腦嗎？只有手機可以嗎？

親自操作完整的 AI 自動化影片製作流程，請先準備 Mac 或 Windows 電腦。手機可以用來拍攝素材、查看實作、接收更新與審片；不代表所有製作步驟都能直接在手機上完成。每份實作會列出使用的工具、版本與設備條件。

需要準備哪些 AI 與剪輯工具？

依你採用的製作流程而定。例如採用 Claude Code 的桌面訂閱流程，需要具備 Claude Code 存取權的付費方案，例如 Pro 或 Max；若要在 CapCut 中開啟與調整剪輯專案，則需要 CapCut 電腦版。實作會說明採用哪一套流程，不需要先把所有工具都訂閱。

CapCut 一定要訂閱 Pro 嗎？

不一定。是否需要 Pro，取決於實作使用的字體、特效與功能。CapCut 電腦版與 CapCut Pro 訂閱是兩回事；涉及付費功能時，會在實作說明中標示。

第三方工具的訂閱費也包含嗎？

不包含。社群內發布的內容與後續更新不另外收取更新費用；Claude 等 AI 工具的訂閱、剪輯軟體的付費功能，以及其他第三方服務費用，則由使用者依所需方案自行負擔。

上面的影片是怎麼做的？

這是用 Jun 的口播與生活素材製作的 52 秒 AI 剪輯實作，包含動態字卡、版面切換與字幕。下方的分鏡就是這支影片的分鏡稿。頁面上放的是無聲版本。後續的新實作與製作方法，都會在社群裡持續更新。

分鏡出來之後，可以自己調整嗎？

可以。分鏡會先排出每一段的畫面與字卡。哪一格不喜歡、想增加或修改，只要在那一格旁邊用文字告訴 Claude，就只調整那一段；沒提到的分鏡維持原樣，不用整支重做。
